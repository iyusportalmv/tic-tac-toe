# 🎮 Tic-Tac-Toe Web App

Aplikasi permainan Tic-Tac-Toe interaktif berbasis web yang dibangun menggunakan **Next.js**, **React**, **TypeScript**, dan **Tailwind CSS**.

🔗 **Live Demo:** [https://tic-tac-toe-iyus.vercel.app](https://tic-tac-toe-iyus.vercel.app)

## ✨ Fitur Utama
- **Dukungan 7 Bahasa:** Antarmuka multi-bahasa yang dapat diganti secara instan.
- **Kustomisasi Tema:** Pilihan tampilan tema visual yang nyaman di berbagai perangkat.
- **Efek Suara (SFX):** Umpan balik audio interaktif saat melangkah, menang, maupun seri.
- **Modal Hasil Permainan:** Notifikasi hasil akhir pertandingan (Menang / Seri) dengan tombol main ulang cepat.
- **Kontrol Permainan Lengkap:** Mendukung fitur *Undo*, *New Round*, dan *Reset Score*.

## 🚀 Menjalankan di Lokal
```bash
npm install
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.
